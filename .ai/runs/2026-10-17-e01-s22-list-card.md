# E01-S22: shared list card + favorites bar (search, category, profile)

Refs #289 · Epic #201
Source doc: .ai/design/przebudowa-handoff/README.md (C2/A3, 6, 7); gaps: .ai/analysis/2026-10-17-design-gap-audit.md §2, §7, §8

## Goal
One shared list-card variant of `RecipeCard` with a favorites-bar variant of `FavoriteButton`, used on /szukaj, /przepisy/{kategoria} and /u/{username} instead of the per-page tiles; plus the C2/6/7 page details from the issue.

## Scope
- `RecipeCard variant="list"`: framed card (`border-2 border-card`, radius 16), thumbnail 96 (search) / 84 (category, profile), title 20/19 px bold, line-height 1.25, 2 lines max, meta lines 16 px `ink-soft`, favorites bar inside the frame.
- `FavoriteButton size="bar"`: 52 px, `border-top: 2px`, "Dodaj do ulubionych" (ink) / "W ulubionych" (surface-accent + action-text). Same optimistic toggle, toast with "Cofnij", guest login link.
- Search (C2/A3): "Kategoria" filter (`?kategoria=`) next to the count, with per-category counts from the same RPC call (RPC caps at 140 rows, the same cap as paging, so no migration); "Nie ma tego, czego szukasz?" at the end of every list; "Szukaj w:" bold, segments 52 px.
- Category (6): icon 52 + H1 28 + "N przepisów w kategorii"; "Jakie {kategoria}?" + hint; summary box "3 przepisy: kruche i czekoladowe"; chip border token at 3:1; "Pokaż kolejne N" cumulative paging; recipe page "Podobne: {tag} {kategoria}" + "też …" captions.
- Profile (7): H1 28, neutral "Przepisy: N" 17 px (S23 genders it), owner block `surface-3`, shared chip look, list cards with favorites bar.

## Non-goals
- No migration, no RPC change. No gendered profile copy (S23, #290). Tile variant on home / Ulubione / Moje przepisy unchanged. Podobne stays a tile grid (S17 4 columns at lg).
- Chip border: the handoff's `#9ca3af` is 2.5:1 on white; CLAUDE.md requires 3:1 for UI borders, so the chip uses `#6b7280` (4.8:1).

## Risks
- Search now always reads up to 140 rows from the RPC (it already counts all matches); fine for the current catalogue size.
- Parallel overflow-guard session edits shared components: merge origin/master often.
