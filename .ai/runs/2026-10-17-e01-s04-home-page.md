# Execution plan: E01-S04 home page (guest and signed-in)

Source doc: `.ai/specs/2026-10-17-e01-s04-home-page.md` (spec PR #247)
Issue: #207

## Goal

Rebuild `/` as the variant-1c home: a guest gets a search hero, popular searches, 8 categories, recent recipes and a CTA; a signed-in user gets a greeting, search, shortcut tiles and categories.

## Scope

- `src/lib/routes.ts` seams (`searchPath`, `categoryPath`), `HOME_CATEGORIES`, `src/lib/home.ts`, `src/lib/speech.ts` (+ unit tests).
- `src/app/components/home/*`, `src/app/page.tsx`, `AddRecipeForm` speech probe, `RecipeCard` token pass.

## Non-goals

- S05 search results/scope (`/szukaj`), S15 notifications banner (slot only), S16 category pages, S10 `/dodaj`, S12 vocative/gender, S11 full-access gate, S17 desktop layouts.
- No migration or production data change.

## Implementation Plan

### Phase 1 — seams and helpers
1.1 Route seams `searchPath` / `categoryPath` + tests
1.2 `HOME_CATEGORIES` + tests
1.3 `home.ts` (`POPULAR_SEARCHES`, `homeGreeting`) + tests
1.4 `speech.ts` probe shared with `AddRecipeForm` + tests

### Phase 2 — home screen
2.1 Home components (search, popular, categories, tiles, CTA)
2.2 `page.tsx` rebuild with S15 slot and S11/S12 interim inputs

### Phase 3 — RecipeCard token pass
3.1 Token/size pass on `RecipeCard`

- A1 interim (guest search/category taps hit login until S05/S16) — ⚠ owner confirmation on spec PR #247.
- `RecipeCard` restyle changes `/recipes` and `/ulubione`; checked visually.
