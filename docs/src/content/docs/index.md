This site renders the project's documentation straight from the repository.
Nothing here is copied: every page is a Markdown file under `context/` or
`.ai/specs/`, read in place at build time. The sidebar is generated from the
folders, so a new file appears on the next build.

- **Foundation** — `context/foundation/`: the living documents (PRD, roadmap,
  tech stack, test plan, pipeline flows and model evaluations).
- **Specs** — `.ai/specs/`: dated feature specifications.
- **Changes** — `context/changes/`: per-change plans and research.

To edit a page, use the "Edit page" link in its footer; it opens the file on
GitHub.
